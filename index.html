The Technical Flow: Under the Hood When a learner clicks "Evaluate Response," a highly orchestrated sequence occurs in the background: Audio Capture & Transcription: The browser utilizes the native Web Speech API to listen to the microphone. It processes the audio stream locally and converts the spoken words into a text string (the transcript). Prompt Construction: The JavaScript takes that transcript and packages it into a strict JSON payload. It does not just send the raw text. It prepends a "System Instruction" which acts as the core programming for the AI, telling it to assume the role of an expert NHS assessor. Algorithmic Evaluation: The payload is sent via a secure POST request to the Gemini 3.5 Flash model. The model analyzes the transcript strictly against the P.I.P.A.V. criteria provided in the prompt, functioning as a real-time assessment rubric. Structured Output Formatting: Because we implemented responseSchema, the AI is forced to return its evaluation in a machine-readable format. It cannot return conversational text. It must return exactly two data points: an integer (the score) and a string (the feedback). Dynamic Branching: The application parses that structured data and uses simple conditional logic (if/else statements) to seamlessly load and play the corresponding video branch based on the final integer score. This immediate, targeted feedback loop directly supports active experimentation and abstract conceptualization within standard learning cycles, allowing the user to instantly understand the consequence of their response. The P.I.P.A.V. Framework Explained To accurately measure a soft skill like conflict de-escalation, the AI needs a concrete, objective rubric. P.I.P.A.V. breaks down the ideal response into five measurable criteria. P - Polite: The foundational layer. The AI checks if the learner maintains a calm, professional tone. It looks for the absence of defensive language, aggressive pushback, or dismissive remarks, ensuring the receptionist remains composed under pressure. I - Investigate: Active problem-solving. The system checks if the learner attempts to find the root cause of the issue by asking clarifying questions, rather than just reacting to the aggression. P - Privacy: A critical compliance check. The AI evaluates if the learner sets appropriate boundaries regarding other patients' information. This includes refusing to show the computer screen and offering to move the conversation to a side room, ensuring strict adherence to data protection and GDPR regulations. A - Acknowledge: Active listening. The AI looks for specific phrases that prove the learner has heard the patient's specific grievance. Instead of generic apologies, it rewards repeating or summarizing the issue so the patient feels seen. V - Validate: Psychological de-escalation. The system checks if the learner normalizes the patient's emotional state without necessarily agreeing with their behavior. Phrases that validate frustration or anxiety are highly rewarded, as they are proven to lower the emotional temperature of an interaction. By grading against this specific rubric, the AI avoids subjective "good or bad" judgments and instead provides clinical, actionable feedback.
